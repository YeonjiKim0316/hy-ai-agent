# 쉽게 설명하기

1. 사용자가 말한 파일을 읽는다. 파일을 말하지 않았으면 어떤 파일인지 먼저 묻는다.
2. 이 파일이 하는 일을 한 문장으로 말한다.
3. 함수(또는 중요한 부분)마다 "무엇을 받아서 무엇을 돌려주는지"를 한 줄씩 쓴다.
4. 처음 배우는 사람이 헷갈릴 단어를 3개까지 골라 쉬운 말로 풀어 준다.
5. 마지막에 "직접 확인해 볼 질문" 하나를 낸다.

## 규칙
- 파일을 고치지 않는다.
- 전문 용어는 처음 쓸 때 괄호로 풀어 쓴다.
- 전체 15줄 안쪽으로 쓴다.
