세션 1 · AI와 처음 일해 보기

1-1

저장소 받기

터미널을 엽니다. Windows는 시작 메뉴에서 PowerShell, macOS는 터미널 앱. 세 줄을 한 줄씩 칩니다.

Windows PowerShell
cd $HOME\Documents
git clone https://github.com/YeonjiKim0316/hy-ai-agent.git
code hy-ai-agent
macOS
cd ~/Documents
git clone https://github.com/YeonjiKim0316/hy-ai-agent.git
code hy-ai-agent

cd $HOME\Documents에서 경로가 없다고 나오면 문서 폴더가 OneDrive로 옮겨진 PC입니다. cd $HOME\OneDrive\Documents(또는 cd $HOME\OneDrive\문서)로 바꿉니다.

VS Code가 열리면 “신뢰합니까?” 창에서 Yes. code 명령이 없다고 나오면 VS Code → File → Open Folder → 문서 폴더의 hy-ai-agent.

확장 두 개를 확인합니다: Python, GitHub Copilot Chat.

안 되면 zip을 풉니다. Windows는 오른쪽 클릭 → 모두 압축 풀기. VS Code → File → Open Folder → hy-ai-agent.

성공 · hy-ai-agent 폴더가 VS Code에 열리고 확장 두 개가 보입니다.

가상환경 만들고 서버 켜기

Terminal → New Terminal을 엽니다. 아래 블록이 하는 일은 세 가지입니다.

  • ① 가상환경(이 프로젝트만의 파이썬 상자)을 만듭니다
  • ② 필요한 패키지를 넣습니다(처음에는 몇 분 걸립니다. 멈춘 듯 보여도 기다립니다)
  • ③ 서버를 켭니다

아래 세 줄을 붙여 넣습니다. 마지막 줄이 서버를 켭니다. 가상환경을 따로 활성화하지 않아도 됩니다.

Windows PowerShell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements.txt
.venv\Scripts\python -m uvicorn app.main:app --reload
macOS
python3 -m venv .venv
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python -m uvicorn app.main:app --reload
성공 · 터미널에 Uvicorn running on http://127.0.0.1:8000이 보이면 서버가 켜진 것입니다. 이 터미널은 그대로 둡니다.

처음 분석하면 AI 모델을 내려받느라 “AI 부품이 아직 준비 중”이 먼저 나올 수 있습니다. 잠시 뒤 다시 누릅니다.

브라우저에서 http://localhost:8000을 엽니다. 리뷰를 넣고 분석을 누릅니다.

성공 · “아직 구현되지 않았어요”가 보이면 정상입니다.

막히면 Windows는 .\start.bat, macOS는 bash start.sh로 한 번에 켤 수 있습니다.
