- 터미널: 글자로 명령을 쳐서 컴퓨터에 일을 시키는 창입니다. (Windows: PowerShell, macOS: 터미널 앱)
- 가상환경(`.venv`): 이 프로젝트만 쓰는 파이썬 상자입니다. 패키지를 여기에만 설치합니다.
- 서버: 요청을 기다렸다가 답을 돌려주는 프로그램입니다. 켜 두는 동안 브라우저가 접속합니다.
- API: 프로그램끼리 주고받는 약속입니다. 주소로 요청을 보내면 약속된 모양으로 답이 옵니다.
- 명세: 무엇을 만들지 적은 글입니다. 규칙과 예시가 들어 있습니다.
- 예시표: 입력과 기대하는 결과를 한 줄씩 적은 표입니다. 한 줄이 테스트 하나가 됩니다.
- 테스트: 코드가 예시대로 움직이는지 자동으로 확인하는 코드입니다.
- 빨강(Red)/초록(Green): 테스트가 실패하면 빨강, 통과하면 초록입니다. 테스트를 먼저 쓰면 처음에는 빨강이 정상입니다.
- git clone(받기): 인터넷에 있는 저장소를 내 PC로 복사해 오는 명령입니다.
- 커밋: 지금 상태를 이름을 붙여 저장하는 것입니다. 나중에 이 상태로 돌아올 수 있습니다.
- Given–When–Then: 테스트를 준비(Given)–실행(When)–확인(Then) 순서로 쓰는 방법입니다.
- 프리모템/포스트모템: 부탁하기 전에 틀릴 곳을 먼저 묻는 것이 프리모템, 다시 부탁한 뒤 처음에 넣었어야 할 것을 적는 것이 포스트모템입니다.
- 에이전트: 질문에 답만 하지 않고 파일을 읽고 고치고 명령도 실행하는 AI입니다.
- Ask 모드/Agent 모드: Ask는 묻고 답만 듣습니다. Agent는 파일을 고치고 명령을 실행합니다.
- MCP: AI에게 도구를 붙이는 약속입니다. 여기서는 AI가 DB를 읽게 하고(review-logs), 최신 공식 문서를 찾게 합니다(Context7).
- 스킬: 글로 적어 둔 업무 순서입니다. AI가 이 순서대로 일합니다.
- AGENTS.md: AI가 일하기 전에 읽는 프로젝트 안내서입니다. 하면 안 되는 일도 적습니다.
- 쿼리(SQL): DB에 묻는 문장입니다. 예를 들어 리뷰가 몇 개인지 셉니다.
- 대시보드: 숫자를 한 화면에 모아 보여 주는 화면입니다.
